# Chat RPG Android v0.1

사용자 목표: AI Game Master처럼 한국어로 자유 행동을 입력하는 본인용 Android 앱을 지금 만들고, GitHub에 소스를 두고 설치할 APK를 제공한다. 사용자 요청의 즉시 구현 지시를 실행 승인으로 적용한다.

## 선택한 구성
Android 8.0 이상, Java Activity와 번들 HTML/CSS/JavaScript UI. 별도 서버 없이 개인 API 키로 OpenAI Responses API에 직접 HTTPS 요청한다. API 키는 Android Keystore AES-GCM으로 암호화한다. 최초 키 입력은 신뢰된 로컬 WebView의 비밀번호 필드와 JS를 잠시 거쳐 네이티브에 전달하고 즉시 지운다. 저장된 키를 JS에 돌려주지 않으며 소스, 백업 JSON, 로그에 포함하지 않는다. 모델 기본값 gpt-6.1-sol, 설정에서 수정할 수 있다. GPT 구독과 API 요금은 별개이며 설정 화면에서 안내한다.

## 기능과 규칙
판타지/헌터/생존 배경 또는 사용자 세계관, 이름과 검사/도적/마법사 직업 설정. 한 번에 자유 행동 하나를 전송한다. AI는 한국어 서사, 선택지, 상태 변경 제안을 구조화 JSON으로 반환하고 앱은 검증 후 원자적으로 적용한다. HP/MP/골드/XP 수치는 앱에서 계산하고 범위를 검증한다. d20 난수는 앱에서 생성하여 AI에 넘기며 응답에서 공개한다. 장비와 NPC, 현재 목표, 위치, 캠페인 요약을 유지한다. 응답이 잘못되거나 네트워크가 실패하면 턴을 소비하거나 기존 상태를 바꾸지 않는다. 중복 전송을 차단한다.

키가 없어도 별도 표시된 오프라인 연습 모드에서 미리 작성한 이야기/전투를 플레이할 수 있다. 이 모드를 GPT 응답처럼 표시하지 않는다. 연습 캠페인과 AI 캠페인은 생성 시 확정하며 임의로 전환하지 않는다.

## 저장과 UI
앱 전용 네이티브 저장으로 자동 저장; 캠페인 목록, 상태/가방/동료 화면, JSON 내보내기/불러오기. 세이브에 키를 포함하지 않는다. 앱 재시작 후 이어 하기. 대화는 최대 120개 저장; AI 요청에는 최근 12개와 요약/현재 상태만 포함한다. 화면은 모바일 터치와 키보드/뒤로가기를 지원하는 한국어 어두운 테마, 큰 입력창, 진행중 취소 대신 오류 후 재시도, 텍스트 출력만 DOM textContent 사용. 배경화면이나 원격 스크립트를 실행하지 않는다.

## 경계와 검증
APK와 소스를 제공하고 서명 유효성, 설치 대상 SDK, 번들 리소스를 확인한다. API 키가 제공되지 않았으므로 실계정 GPT 응답은 검증할 수 없으며 문서 기반 요청/응답 처리와 로컬 오류/연습 흐름을 검증한다. 기존 kow565/-v.1 저장소 main을 바꾸지 않고 chat-rpg 브랜치에 독립 프로젝트 트리를 올린다. 재현 가능한 GitHub Actions 빌드도 추가한다. 개발용 APK 서명 키는 소스와 분리하여 보관한다.
